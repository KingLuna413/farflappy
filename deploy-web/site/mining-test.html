How one test run works, step by step

  1. Agent plays: a simple agent decides when to flap based on the next pipe gap. This is the "agent" in Agent League.
  2. Replay is recorded: seed + flap timing list + final score. A SHA-256 hash of that replay is computed in your browser.
  3. Server re-simulation (simulated here): the same seed and flap list are run again. If the re-run score matches the claimed score, the result is VERIFIED.
  4. Points: verified score × 10 points, plus +100 points if the score reaches 20 or more (a win in this test).
  5. Mining / Claim: points convert to sample $FLAP at 10 $FLAP per point. In production this rate comes from the season reward pool, not a fixed rate.

Tampered test: one flap input is changed after the run. The re-run score no longer matches, so the result is REJECTED and no points are given. This is how forged scores are blocked.
