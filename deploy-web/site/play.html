How a verified run will differ

1. The server locks a seed and shows only its hash before play. 2. You play one session, once. 3. The seed is revealed after play and the server re-simulates your flap list. Only a matching re-simulation counts.

Production caps, planned

Reward score is capped per game (example cap: 100), counted games per Pilot per day are capped (example: 10), and the daily reward is based on your best verified score, not the sum of all games. These are planned example caps from the design, not contract code yet.
