🐦 FarFlappy AI Arena — Browser Deployer

Deploy FlapPilot, $FLAP, dan FlapArena langsung dari ekstensi Rabby di browser-mu. Tanpa server, tanpa private key yang dikirim ke siapa pun.

Keamanan — baca dulu.
  • Tidak ada backend. Halaman ini tidak punya server, tidak menyimpan private key, dan tidak pernah mengirim kunci ke mana pun. Semua tanda tangan terjadi di ekstensi Rabby-mu sendiri lewat provider Rabby (EIP-6963 io.rabby / isRabby). Wallet lain tidak dipakai sebagai pengganti.
  • Wallet agent Binance (luna404.ai, MPC) TIDAK bisa connect ke web ini seperti MetaMask. Web ini memakai EOA biasa lewat ekstensi Rabby di browser desktop. Wallet agent bisa dipakai setelahnya sebagai verifier/owner: masukkan alamatnya di Langkah 4, dan setelah deploy selesai, transfer ownership secara manual (lihat Langkah 8, opsional).
  • Jangan refresh halaman selama sebuah deploy/transaksi berjalan. Tunggu sampai statusnya terkonfirmasi.
  • Kontrak tidak upgradeable. Deploy mainnet tidak bisa dibatalkan. Web ini tidak membuat kontrak menjadi aman — keamanan tetap dari testnet dan audit.

Langkah 1 — Connect wallet

Belum terhubung.
Pengaman mainnet — wajib diisi, kalau tidak tombol deploy tetap nonaktif.

Ketik persis DEPLOY MAINNET dan centang ketiganya:

Saya sadar kontrak belum tentu diaudit, dan deploy mainnet tidak bisa dibatalkan.
Alamat distribusi $FLAP sudah final (mainnet harus multisig/vesting, bukan deployer pribadi).
Resolver produksi klaim .ai sudah ada (bukan allowlist testnet).

Langkah 2 — Deploy FlapPilot

ERC721, tanpa argumen constructor. Max supply 10.000, harga mint 0,01 BNB, maks 5 per wallet (dari kontrak).

Langkah 3 — Deploy FlapToken ($FLAP)

ERC20, supply tetap 1.000.000.000. rewardPool diisi deployer sebagai interim, karena FlapArena belum ada saat token di-deploy — 40% reward akan dipindahkan ke arena di Langkah 6. Untuk mainnet, keempat alamat distribusi harus multisig/vesting, bukan deployer pribadi.

Langkah 4 — Deploy FlapArena

Verifier di sini adalah alamat yang boleh memanggil recordVerifiedScore dan yang signature-nya diterima mintAgent lewat FlapPilot.setVerifier.

Default verifier = alamat publik wallet agent 0x9707C99D8247fBBB5E806a389160372602578009 (luna404.ai). Kalau dipakai, permit harus ditandatangani wallet itu sendiri (mis. via baw sign-message), bukan oleh server key — karena wallet MPC tidak punya key yang bisa diekspor. Untuk permit otomatis dari server, isi verifier dengan alamat key server.

Langkah 5 — Setup

Dua transaksi: FlapPilot.setArena(arena) lalu FlapPilot.setVerifier(verifier).

Langkah 6 — Pindahkan 40% reward ke arena + verifikasi

Transfer 400.000.000 $FLAP dari deployer ke FlapArena, lalu halaman membaca saldo arena on-chain dan menampilkannya sebagai bukti.

Langkah 8 (opsional, manual) — Transfer ownership ke wallet agent


Langkah ini tidak dijalankan otomatis oleh halaman ini. Kalau kamu ingin wallet agent (luna404.ai) menjadi owner setelah deploy, lakukan manual setelah semua langkah di atas terverifikasi, misalnya lewat tab Write Contract di BscScan dengan wallet deployer yang terhubung: panggil transferOwnership(0x9707C99D8247fBBB5E806a389160372602578009) di FlapPilot dan di FlapArena. Setelah itu, hanya wallet agent yang bisa memanggil fungsi onlyOwner (termasuk setVerifier / setArena). Token $FLAP tidak punya owner, jadi tidak ada yang perlu ditransfer untuk token.
